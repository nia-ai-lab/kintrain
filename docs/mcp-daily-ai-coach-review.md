# MCP Daily AIコーチレビュー保存仕様

## 1. 対象

`save_daily_ai_coach_review`は、指定日のDaily記録へAIコーチが作成した総合レビューを保存する。

保存項目:

- `aiCoachReview`: レビュー本文（1〜5000文字）
- `aiCoachReviewedAt`: バックエンドが保存時に設定するUTC日時

レビューは、対象日の筋トレ、日記、食事、回復状態と必要な過去履歴を確認して作成する。MCPツールはレビューの生成を行わず、AIが作成したレビューを安全に保存する。

## 2. 保存条件

- `date`と`aiCoachReview`を必須とする。
- ユーザーがレビューの保存を明示した場合だけ実行する。
- 既存レビューがない場合は`overwriteExisting`を省略して保存する。
- 既存レビューがある場合は競合として拒否する。置き換え内容をユーザーへ提示して承認を得た後だけ`overwriteExisting: true`で保存する。
- 追記は行わず、再レビューは全文を置き換える。

## 3. データ保護

- DynamoDBの部分更新を使用し、日記、食事、体組成、回復状態、その他トレーニングなど、レビュー以外のDaily項目を保持する。
- 通常のDaily APIでは`aiCoachReview`と`aiCoachReviewedAt`を書き込めない。
- MCPの取得結果と分析エクスポートには両項目を含める。
- 監査ログにはツール名と引数名だけを記録し、レビュー本文とユーザーIDを含めない。

## 4. 受け入れ基準

- 新規レビューを指定日のDailyへ保存できる。
- 保存日時がバックエンドで設定される。
- 既存レビューの明示されていない上書きを拒否する。
- `overwriteExisting: true`で承認済みのレビューを置き換えられる。
- 保存前後でレビュー以外のDaily項目が変化しない。
- Daily画面、`get_daily_record`、`get_daily_records`、分析エクスポートでレビューを確認できる。
