- `ログイン`

- 未ログイン状態で `/dashboard` などへ直接遷移した場合は `/login` へリダイレクトする

## 4.1 パスワード再設定（`/password-reset`）

- 目的
- Cognito のパスワード再設定フローに対応する
- 画面モード
- 新しいパスワード必須（`CONFIRM_SIGN_IN_WITH_NEW_PASSWORD_REQUIRED`）
  - 入力: 新しいパスワード / 確認
  - 操作: `設定してログイン`
- メール再設定
  - 入力: メールアドレス
  - 操作: `確認コードを送信`
  - 送信後入力: 確認コード / 新しいパスワード / 確認
  - 操作: `パスワードを再設定`
- 導線
- `ログイン画面へ戻る`

## 6. トレーニング実施画面（`/training-session`）

### 6.1 画面構成

- ヘッダー
- タイトル: `トレーニング実施`
- 日付表示
- `下書きをクリア` ボタン（全種目の下書きを破棄）
- 下書き状態表示（下書きがある場合のみ `下書き保存中: ...`）
- 画面下部固定: `記録して終了`
- 対象日の `DailyTrainingPlan` があれば「今日のメニュー」として初期表示する
- 一時セットとAI作成セットはバッジで識別する

### 6.2 種目カード

- 表示要素
- `優先 {n}`
- 種目名表示: `trainingName : bodyPart : equipment`（AI生成時は末尾に ` (AI生成)` を付与）
- `直近`（最新実績、なければ `未実施（メニュー既定値...）`）
- `今日の目標`（セット固有の重量、回数範囲、セット数）
- `説明`（説明がある場合のみ表示。初期状態は折りたたみ、展開時は改行を保持し、長文は説明欄内でスクロール）
- 操作
- `前回と同じ`: 最新実績を入力欄へ反映
- `目標どおり入力`: セット固有の目標を入力欄へ反映
- `入力クリア`: 当該種目を今回下書きから削除
- 入力欄
- `重量`（`step=0.01`、空欄許可、placeholderに既定値）
- `回数 ({min}回 - {max}回)`（整数、空欄許可、`min/max` は `TrainingMenuItem.defaultRepsMin/defaultRepsMax` を表示）
- `セット`（整数、空欄許可、placeholderに既定値）
- `メモ`（今回の実施記録用。メニューの説明とは独立し、説明を初期値に使用しない）
- 任意入力
- `セット詳細を入力` / `セット詳細を閉じる`
- セット詳細は各setごとに重量/回数を入力

### 6.3 入力状態ルール

- `空欄`: 未入力
- 重量の `0`: 自重種目などの追加重量なしを表す有効値
- 回数またはセットの `0`: 無効値（保存対象外）
- `入力クリア`: 当該種目をドラフトから削除
- 正式保存対象は `重量が0以上` かつ `回数/セットが正の値` の種目のみ
- `記録して終了` で保存対象が0件の場合は保存せずメッセージ表示
- 1回の保存で登録できる種目数は最大12件
- `記録して終了` 押下時は即保存せず、確認モーダルを表示する
- 確認モーダルには保存対象の種目・重量・回数・セット・メモを表示する
- 入力途中の種目は「今回の保存対象には含まれない」一覧として表示する

## 7. トレーニングメニュー管理（`/training-menu`）

### 7.1 管理タブ

- `メニューセット`: セット一覧、セット固有処方、今日使うセットを管理
- `種目一覧`: セットに依存しない全種目マスタを検索・登録・編集・削除
- `AIでメニュー生成` ボタン（`/training-menu/ai-generate`）
- 種目の説明、部位、用具、重量入力方式は種目マスタで管理する
- 目標重量、回数範囲、セット数、推奨間隔、補足はセット内種目で管理する

### 7.2 メニューセット

- 恒常セットと一時セットを作成できる
- 既存種目を検索して追加できる
- セット内処方を編集し、「変更を保存」でまとめて保存する
- `今日使う` で対象日の `DailyTrainingPlan` に設定する
- `セットから外す` と `種目自体を削除` を分離する

### 7.3 種目一覧

- 種目名、部位、用具で検索できる
- セット未所属の種目も表示する
- 各種目に使用中セット数を表示する
- 種目マスタを新規登録、編集、削除できる

## 8. AIメニュー生成（`/training-menu/ai-generate`）

- タイトル: `AIメニュー生成`
- 入力項目
- 方針: `マシンのみ` / `マシン + フリーウェイト` / `フリーウェイトのみ`
- 目標: `筋肥大` / `減量` / `維持`
- 週間頻度（1..7）
- ジム施設入力（名称または設備説明URL、必須）
- 個別要求（任意）
- 操作
- `AIに提案してもらう`
- 条件送信後の追加入力
- `この内容で登録`
- `新規チャット`（条件変更時は `条件変更で新しい提案を開始`）
- `メニューへ戻る`
- 表示
- ユーザー／AIのチャット、Runtime状態、Markdown応答
- 条件が変わった場合の注意表示
- 会話状態は通常AIチャットと分離し、`sessionStorage` に保持する
- 登録は MCP `create_daily_training_plan_from_ai` を使用する
- 既存種目はIDで再利用し、該当種目がない場合は新規種目を作成できる
- 一時セットとして対象日の `DailyTrainingPlan` に設定する

## 9. カレンダー（`/calendar`）

- 月移動: `前月` / `次月`（`month=YYYY-MM`）
- 日付セル表示
- 実施日: ドット表示
- 体調/気分: 上下2本の色バー（未入力は淡色プレースホルダ）
- 日付タップで `Daily` へ遷移

## 10. Daily（`/daily/:date`）

- ヘッダー
- タイトル `Daily`
- `カレンダー` / `トレーニング開始` 導線
- `保存` ボタン
- 保存状態表示（`保存中` / `最終保存` / `未保存`）
- 入力は自動保存（3秒デバウンス）し、`保存` ボタンで即時保存可能
- 体重・体脂肪率
- `体重(kg)` / `体脂肪率(%)` / `測定時刻` を1行3列表示
- 体調・気分
- 10段階グラデーションスライダー入力
- コメント
- `体調` / `気分` 共通メモ
- 日記
- 自由記述
- その他トレーニング
- 文字列追加 / 削除
- 当日の筋トレ内容
- 当日 `GymVisit` の種目を統合した番号付き一覧（1, 2, 3...）
  - 種目名表示形式: `トレーニング名 : 部位 : 用具`（AI生成時は末尾に ` (AI生成)` を付与）

## 11. AIチャット（`/ai-chat`）

- ヘッダー表示
- ラベル: `AI コーチ`
- 表示名: `{characterName}`（既定: ニャル子）
- アイコン: `avatarImageUrl`（default固定）
- チャット本文
- AI/ユーザの吹き分け表示
- AIメッセージにアイコンと名前表示
- 入力
- textarea + `送信`
- AgentCore RuntimeのSSE応答を逐次表示
- Runtime接続情報がない環境では、通常チャットのみモック応答へフォールバック
- AIメッセージはMarkdown表示し、外部リンクは別タブで安全属性を付けて開く

注記:
- 通常AIチャットからメニュー登録を行う専用UIは提供しない。メニュー登録は `/training-menu/ai-generate` を使用する。

## 13. 日時表示・入力フォーマット

- 画面表示
- 日付: `YYYY/MM/DD`
- 時刻: `HH:mm`
- 測定時刻入力: `input[type=time]`
- API/保存側
- 日付: `YYYY-MM-DD`
- 時刻: RFC3339
- トレーニング実施時刻はバックエンドで RFC3339 UTC（秒精度）保存
- 画面表示・AI利用時は `timeZoneId` 基準ローカル時刻へ変換

## 14. PWA（iPhoneホーム画面追加）

- `manifest.webmanifest` を配信し、ホーム画面追加に対応する。
- iOS向けメタタグを設定する。
- `apple-mobile-web-app-capable: yes`
- `apple-mobile-web-app-title: KinTrain`
- `apple-touch-icon: /icons/icon-180.png`
- 起動モードは `standalone` とし、ホーム画面起動時に単独アプリ風表示とする。
- 現時点ではService Worker未導入のため、オフライン利用は対象外とする。

## 15. 受け入れ基準（実装準拠）

- 未ログイン時は `/login` のみアクセス可能であること。
- `/login` でメールアドレス/パスワード入力後にアプリへ遷移できること。
- `/password-reset` でパスワード再設定操作ができること。
- `/dashboard` から `トレーニング開始` と `本日の日記をつける` に遷移できること。
- `/training-session` で `前回と同じ` / `入力クリア` / `セット詳細` が機能すること。
- `/training-session` / `/daily/:date` / `/dashboard` の種目名が `トレーニング名 : 部位 : 用具` 形式で表示されること（AI生成時は末尾に ` (AI生成)` を付与）。
- `/training-session` の入力はリロード後も復元されること（localStorage）。
- `/training-session` は1回の保存で12件を超える種目を登録できないこと。
- `記録して終了` で保存され、`/daily/:date` で内容確認できること。
- `/training-menu` で追加/編集/削除/上下並び替えができること。
- `/training-menu/ai-generate` で提案反映できること。
- `/calendar` で実施日と体調/気分の色バーを確認し、日付遷移できること。
- `/daily/:date` で体重・体脂肪率・測定時刻・体調・気分・日記・その他トレーニングを更新できること。
- `/daily/:date` は自動保存（3秒デバウンス）と保存ボタンの両方で更新できること。
- `/settings` でユーザ情報とAIキャラクター名/口調を更新できること。
- `/settings` からログアウトでき、`/login` へ遷移すること。
- `/ai-chat` でAgentCore SSE応答（未設定環境ではフォールバック応答）が表示されること。
- iPhoneでホーム画面に追加した場合、standalone起動できること。
